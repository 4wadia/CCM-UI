# Forma Cards for Android

Native Android credit card management app.

## Included

- Android Studio project under `app/`
- Signed installable package at `FormaCards.apk`
- Manually added card profiles, local transaction alert import, light and dark themes

## Open and build

Open this folder in Android Studio with Android SDK 35 installed. The app uses minSdk 24 and targetSdk 34.

## Privacy

Transaction alert import is opt-in and uses Android Notification Access. Parsed transaction records are stored locally by the app.
